# Печатай — крупные буквы

PWA-приложение с крупной русской клавиатурой для тренировки печати на планшете. Сделано для детей с задержкой развития — большие кнопки, крупный текст, простой интерфейс.

## Возможности

- Крупная русская клавиатура (раскладка ЙЦУКЕН)
- Только нужные клавиши: буквы, пробел, Shift и Enter
- Большая область для отображения напечатанного текста
- Отзывчивые кнопки с анимацией нажатия
- Работает как PWA — можно установить на iPad на главный экран
- Работает офлайн после первой загрузки

## Локальный запуск

```bash
# Python 3
python3 -m http.server 8080

# или Node.js
npx serve .
```

Откройте http://localhost:8080 в браузере.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и запушьте код в ветку `main`
2. В настройках репозитория: **Settings → Pages → Build and deployment → Source: GitHub Actions**
3. При каждом push в `main` приложение автоматически публикуется

Адрес будет: `https://<ваш-username>.github.io/big-letters-typing/`

## Установка на iPad

1. Откройте приложение в Safari
2. Нажмите кнопку «Поделиться» (квадрат со стрелкой)
3. Выберите «На экран Домой»
4. Приложение откроется в полноэкранном режиме без адресной строки
